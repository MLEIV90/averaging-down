# Quant Strategy Engine — SPY / BTC / GLD

EOD systematic research and portfolio engine with a local Streamlit UI.

## Run
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app/main.py

The app opens at http://localhost:8501.

## Architecture
- src/data: market data acquisition, validation and loading
- src/features: indicators, volatility and regime
- src/strategy: alpha, scale-in, exits and state machine
- src/risk: sizing and portfolio risk
- src/portfolio: allocation and capital deployment
- src/execution: future broker abstraction
- src/backtest: research/backtest engine
- src/core: shared models
- app: local web UI
- scripts: command-line entry points
- tests: automated tests

No live orders are generated by this initial version.
